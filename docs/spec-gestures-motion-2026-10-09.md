# 手势与动画（B）设计

- 日期：2026-10-09
- 状态：待评审
- 前置：`docs/spec-visual-depth-motion-2026-10-08.md`（已落地 B2 层次 + M2 动效）；`docs/spec-cover-viewer-2026-10-09.md`（A，已落地）

## 1. 背景与目标

播放页与迷你条目前只有点击交互。本轮加入三条跟手动效手势，提升手感：

1. **迷你条左右滑** → 切换 上一首/下一首（跟手轮播）。
2. **竖屏播放页 右→左滑** → 进入 `LyricsView`（跟手平移，可反向退回）。
3. **播放页 顶栏 上→下滑** → 抽屉式隐藏（跟手平移 + 遮罩，过小可打断）。

三处都复用现有动效令牌 `AppMotion`，支持动画中途反手接管。

## 2. 范围

### 2.1 本轮做

1. 新增「相邻曲目」派生 provider（上一首/下一首 `Track?`）。
2. 迷你条跟手轮播（左右滑切歌）。
3. 竖屏播放页跟手横滑进出歌词（封面区 + `LyricsPreview` 起手）。
4. 播放页顶栏跟手下滑隐藏（抽屉 + 遮罩，横竖屏都生效）。
5. 三处手势的手势仲裁与阈值判定，保证与现有交互不冲突。

### 2.2 本轮不做

- 封面查看器 A 的遗留项（双击缩放、Esc 关闭、错误态回退封面等）。
- 系统级返回手势接管。
- 列表/网格的滑动手势。

## 3. 设计

### 3.1 相邻曲目 provider

`PlaybackState` 只暴露 `currentTrack` 与 `hasNext/hasPrevious`，不含相邻曲目对象。新增：

```dart
/// 当前队列中「上一首」曲目，无则 null。
final previousTrackProvider = Provider<Track?>((ref) { ... });

/// 当前队列中「下一首」曲目，无则 null。
final nextTrackProvider = Provider<Track?>((ref) { ... });
```

- 数据来源：`ref.watch(playbackStateProvider)`（触发重建）+ `ref.read(playbackControllerProvider).queue`（`PlaybackQueue.tracks` / `currentIndex`，配合 `nextIndex`/`previousIndex` 语义）。
- 保持与切歌一致：`RepeatMode.one` 时相邻即当前曲；`RepeatMode.off` 到端点时为 `null`（与 `hasNext/hasPrevious` 对齐）。

### 3.2 手势 ①：迷你条跟手轮播

- 迷你条的内容（封面 + 标题/艺人）作为水平三格：`[上一首][当前][下一首]`；**左滑=下一首**（下一格从右进入）、**右滑=上一首**。
- 拖动时整列随手指平移（`AnimationController` + 位移增量）；相邻格由 `previousTrackProvider`/`nextTrackProvider` 渲染（封面用 `CoverImage`，播放中的格子无进度条/控件）。
- 松手判定：位移超过**宽度的一定比例**或速度超过阈值 → 提交（调用 `controller.previous()/next()` 并动画到新位置）；否则回弹。
- 队列到头/单曲无相邻格：位移受限（阻尼），不提交。
- 轻点（未超 tap slop）仍打开播放页。
- 切歌后当前格内容随之更新；动画期间可反手打断。

### 3.3 手势 ②：竖屏横滑进出歌词

- 起手区：**封面区 + `LyricsPreview`**；进度条与控件区不响应。
- 进入：拖动时 `LyricsView` 从**右侧**跟手滑入，封面区向左让位（可带淡出）；超过阈值松手 → `lyricsExpanded = true`，否则回弹。
- 退出：在歌词页**左→右拖动**跟手退回封面。
- 点击进入/收起、`LyricsView` 的纵向滚动、自动居中均保留。
- 横屏不适用（本就左右双栏同显）。
- 实现上以「双栏水平跟手位移」承载 `LyricsView` 与 `_PortraitNormal`，替代当前的 `AnimatedSwitcher` 纵向切换（最终视觉保持：进入歌词 / 收起封面）。

### 3.4 手势 ③：顶栏下滑隐藏（抽屉）

- 起手区：**header（标题/艺人行）**。
- 拖动时**整页竖直向下跟手平移**；背后应用上覆盖一层随位移**线性渐显的暗色遮罩**。
- 超过阈值松手 → 继续滑出并 `Navigator.pop`；未过 → 回弹（过小可打断，动画中途可反手）。
- 横竖屏都生效。
- 与返回按钮一致：结果都是关闭播放页。

### 3.5 动画与状态

- 三处均由 `AnimationController` 驱动跟手位移，时长/曲线取 `AppMotion`（回弹与提交用 `standard`，抽屉提交用 `emphasized`）。
- 全部支持动画中途反手接管（新拖动重定向控制器）。
- 阈值：位移 ≥ 对应轴尺寸的约 **40%**，或速度 ≥ 约 **700 px/s**，即提交；否则回弹。

### 3.6 冲突与边界

- 下滑只从 header 起手 → 不抢 `LyricsView` 纵向滚动。
- 歌词横滑只从封面/预览起手 → 不抢进度条横向拖动。
- 封面 长按/右键（查看器 A）与横滑不冲突（拖拽 vs 点击/长按）。
- 队列到头/单曲：轮播阻尼、不切换。
- 未播放/歌词为空：手势照常（进歌词页显示占位）。

## 4. 架构与影响

- **新增**：相邻曲目 provider；若需要，共享跟手手势控件（水平跟手位移、竖直抽屉）。
- **修改**：`lib/features/player/mini_player_bar.dart`（轮播）、`lib/features/player/player_screen.dart`（歌词横滑 + 抽屉）。
- 无数据层/信息架构变化，无新依赖。

## 5. 错误处理

纯交互层，无新增错误路径。队列为空、单曲、无歌词等均由现有占位/布尔标志覆盖。

## 6. 测试策略

- **相邻 provider**：`RepeatMode.off/all/one` 与端点的上下曲取值。
- **迷你条**：左滑过阈值 → `next()`；右滑 → `previous()`；小滑 → 回弹不切；到头 → 不切；轻点 → 打开播放页。
- **竖屏歌词**：封面横滑过阈值 → 进入歌词；反向 → 退回；小滑 → 回弹；进度条拖动仍能 seek；歌词仍能纵向滚动。
- **抽屉**：header 下滑过阈值 → 弹回上一层（`pop`）；小滑 → 不关闭；横竖屏都生效。
- **回归**：`flutter analyze` 干净 + 全量测试绿。

## 7. 验收标准

- `flutter analyze` 无问题；全量测试通过。
- 迷你条可跟手左右滑切歌，动画无缝、可打断；轻点仍打开播放页。
- 竖屏可从封面/歌词预览右→左跟手滑入歌词，反向可退回；进度条与歌词滚动不受影响。
- 播放页顶栏上→下跟手滑动可抽屉式隐藏，过小回弹；横竖屏都生效。
- 既有交互（点击展开/收起歌词、进度 seek、封面查看器、返回按钮）行为不变。

## 8. 风险与取舍

- **手势竞技场**：跟手拖动与轻点、纵向滚动共存，需按起手区域与主轴方向正确分流；实现时先用测试覆盖冲突场景。
- **轮播相邻格数据**：依赖新增 provider 与队列一致性；单曲/端点要阻尼而非报错。
- **替换 `AnimatedSwitcher`**：竖屏歌词切换改为跟手平移，需保持既有视觉与 `lyric-current` 行为（自动居中、占位）。
- **抽屉与路由**：`PlayerScreen` 现为淡入 `PageRouteBuilder`；抽屉提交后 `pop` 会叠加该淡出，视觉上以「先滑出再淡出」为准，若观感别扭再调整路由。
